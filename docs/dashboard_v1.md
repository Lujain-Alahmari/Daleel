# Dashboard محلي
واجهة لمسار الأسئلة بالنسخة المقيمة، ونتائج اختبار الأسئلة العشرين، وتصفح corpus.
Gemini Flash-Lite يولد الإجابة من النصوص المسترجعة باستخدام مفتاح .env المحلي؛ الحزمة لا تحتوي المفتاح.
لا تغيير في prompt أو قواعد التحقق، ولا تفعيل لعتبة E5.
زر الإجابة وحده يرسل طلب توليد واحدا؛ التنقل بين الصفحات وفلاتر النصوص لا يرسل طلبات.
تخزن الإجابة في جلسة المستخدم؛ أخطاء التحقق منفصلة عن الامتناع لعدم كفاية النصوص.
السجلات الجديدة: reports/dashboard_live_v1. لا تعديل على نتائج الاختبار.
يستمر استخدام أدوات البحث في الذاكرة مع قفل لمنع تداخل الجلسات.
لا توصف نسبة نجاح التنفيذ بأنها دقة عامة. تقييم عضوين مستقلين واتفاقهما لم يسجلا بعد.
تحليل السياسات غير موصول؛ يضاف عند استلام مكونه من الفريق.

داخل بيئة pdpl-copilot:
python -m pip install -r requirements-dashboard.txt
python -m streamlit run app.py

يلزم التثبيت والتشغيل لمراجعة الواجهة بصريا. الفحوص المحلية لا تستخدم Gemini.
تبقى البيانات والفهرس والاعتماديات الأصلية في المشروع. لا يرفع .env إلى المستودع.
