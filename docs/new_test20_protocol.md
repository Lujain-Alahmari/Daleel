# خطة التشغيل والتقرير — التقييم الجديد
النسخة: الأدوار ضمن التعليمات فقط، مع بقاء فحوص المصادر والمراجع والمتطلبات.
20 سؤالا جديدا: 10 عربي و10 إنجليزي؛ 8 مباشرة، 8 سيناريوهات، 4 خارج النطاق.
لا توجد أسئلة مطابقة حرفيا للأسئلة الـ60 أو أمثلة التحقق الأربعة؛ قد تتقاطع الموضوعات القانونية لأن corpus واحد.
تثبت المجموعة والكود والمصادر قبل التشغيل. أي تعديل بعدها يتطلب تجربة جديدة موثقة.
حتى 20 طلب Gemini أوليا. لا إعادة تلقائية للمحاولات الفاشلة أو المقاطعة.
لا يقرأ المشغل الإجابات المرجعية؛ يحفظها الفريق للمراجعة والتقييم فقط.
جميع الأخطاء تدخل التقرير؛ لا تحسب فشل API/التحقق امتناعا صحيحا.
الصحة/الارتباط/دعم المراجع/الاكتمال الضروري: 0 ضعيف، 1 جزئي، 2 جيد.
الاكتمال يتبع ما يلزم للإجابة الصحيحة على السؤال، لا عدد المواد أو طول الجواب المرجعي.
يقيم عضوان الإجابات بشكل مستقل ويحسب اتفاقهما حيث يتطلب التكليف؛ لا يعلن اتفاق لم يقس.
يعرض التقرير والعرض النهائي نتائج هذا الاختبار وهذا الإصدار فقط، مع العدد والأخطاء وحدود العينة.
تظل السجلات الموجودة محفوظة، ولا تستخدم درجات إصدار مختلف في هذا التقرير.
اختيار أسئلة جديدة بعد تطوير النظام لا يجعلها ضمانا لصحة كل الأسئلة المستقبلية.

التشغيل:
python .\src\evaluate_new_test20.py
فحص تجهيز فقط، لا يحمل النماذج ولا يستهلك API.
python .\src\evaluate_new_test20.py --run --limit 3
