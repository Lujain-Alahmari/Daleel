# نسخة الأدوار ضمن التعليمات فقط
ملف مستقل: src/chat_rag_roles_prompt_only.py
لا يستبدل ملف النسخة المختبرة ولا يعدل تقارير التطوير أو الاختبار.

التغيير: حذف actors وactor_ids وrole_status من مخطط مخرجات النموذج والتحقق البرمجي.
تبقى الأدوار جزءا من التعليمات وصياغة الادعاءات القانونية؛ عند عدم وضوحها يصاغ الحكم بشرطه دون اختلاق دور.
تبقى فحوص عضوية المصدر، ومطابقة النص ومواضعه، وربط الادعاءات بأجزاء السؤال، وفحوص أدلة المتطلبات.
قد تستمر حالات تعذر بسبب API أو فشل الأدلة. لا يعد هذا التغيير ضمانا لصحة معنى الأدوار.

الفحص المنجز دون API:
إسقاط حقول الأدوار فقط من مسودات التطوير القديمة ثم اختبار البنية؛ ليس توليدا جديدا أو قياس تحسن.
اجتازت 24 مسودة مقبولة سابقا، وظلت 5 مسودات ذات أدلة ناقصة مرفوضة، ولم توجد مسودة لخطأ API السادس.
اختبارات سلبية: مقطع مجهول، اقتباس معدل، مصدر غائب، ادعاء غير موجود، نطاق سؤال مختلف، وتغطية مفقودة.
لا تنقل درجات الاختبار القديم إلى هذه النسخة.

الاستخدام:
--question يتيح سؤالا جديدا مع نفس البحث الحي؛ بدون --run لا يحمّل النماذج ولا يستدعي API.
--saved-context متاح للفحص المحلي، ولا يعاد توليد الاختبار المحجوز لتحسين أرقامه.
--run مع سؤال جديد ينفذ البحث وطلب Gemini واحدا.
تقارير النسخة: reports/rag_roles_prompt_only_v1.
الإشعار والمراجع المجمعة باسم الوثيقة ورقم المادة محفوظة، ولا يظهر جدول أدوار منفصل.

التحقق التالي: الأسئلة الأربعة الجديدة المرفقة للفحص التشغيلي النوعي فقط؛ لا تمثل اختبار تعميم مستقلا.
راجع من يتحمل الواجب، ومن يوافق، وما إذا كان الدور مشروطا، وأن المصدر يدعم العبارة.
السؤال غير المغطى ينبغي أن يقود إلى امتناع واضح دون اختلاق منتج.
